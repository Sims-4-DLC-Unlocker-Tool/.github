# 🎮 Automatic Sims 4 DLC Unlocker Tool

**S4Unlocker** is an all-in one universal tool that automatically  unlocks DLCs in **Sims 4**, both in modded and unmodded versions of the game, currently working on Steam, Epic Games and EA Play versions of the game.

## 🧰 Dependencies:

- A ** `Steam`, `Epic Games` or `EA Play` version** of Sims 4
- The **latest release** of Unlocker

## 🚀 Getting Started

   1. Open the unlocker file.
   2. Change the platform to the one your using under settings.
   3. Choose which profile to use, and whether to spoof currencies & level.
   4. Go to home page and press launch and the game should automatically begin launching.

**Features:**
- Unlock all DLCs (Expansions, Game Packs, and Stuff Packs) for The Sims 4

- Frequently updated to remain compatible with the latest Sims 4 content

## 🔧 **Troubleshooting**

| Problem                        | Solution                                                                 |
|---------------------------------|--------------------------------------------------------------------------|
| DLCs not showing in-game        | Ensure Unlocker was run as Administrator and restart Steam.              |
| Game crashes after launch       | Use the “Uninstall” option in CreamAPI and reinstall unlockers.         |
| Missing DLL errors              | Reinstall Koaloader via CreamInstaller’s context menu.                   |
| Still doesn’t work              | Re-run CreamAPI and refresh Steam appinfo for onster Hunter Wilds.    |
